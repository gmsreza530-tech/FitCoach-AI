# FitCoach AI — نسخه کامل MVP تلگرام

این نسخه یک MVP قابل اجرا و قابل توسعه است؛ شامل محیط ورزشکار، محیط مربی، دریافت فایل Excel دانش مربی، ساخت برنامه با کمک AI، تأیید مربی، ثبت پیشرفت، مدیریت دسترسی و اسکلت فروش تکی/اشتراک.

## قابلیت‌ها
### ورزشکار
- ثبت پروفایل: سن، جنسیت اختیاری، قد، وزن، هدف، سابقه، امکانات، تعداد جلسات، خواب/ریکاوری.
- پرسشنامه سلامت با امکان ثبت چند آسیب/بیماری/محدودیت، دارو و توضیحات.
- دریافت برنامه تمرین ساختاریافته؛ ثبت وضعیت جلسه و پیشرفت.
- گفت‌وگو با مربی هوشمند با استفاده از پروفایل و دانش واردشده مربی.
- ارسال عکس برای مربی/تحلیل متنی اولیه؛ تحلیل خودکار عکس فقط در صورت تنظیم مدل بینایی سازگار فعال می‌شود (در این نسخه عکس به‌عنوان پیوست ذخیره/ثبت نمی‌شود و به‌صورت امن از کاربر شرح متنی خواسته می‌شود).

### مربی
- شناسایی مربی با Telegram ID در `COACH_IDS`.
- بارگذاری فایل Excel با پسوند `.xlsx` یا `.xlsm` در ربات.
- استخراج محتوا از همه Sheetها و ستون‌ها و افزودن به پایگاه دانش مربی.
- حذف/جایگزینی دانش واردشده با بارگذاری فایل تازه؛ داده‌های قبلی در MVP حفظ می‌شوند و می‌توانند با دستور پاک‌سازی ادمین حذف شوند.
- مشاهده درخواست‌های برنامه و تأیید/رد برنامه.
- حالت تأیید: `both` یعنی همه برنامه‌ها در انتظار تأیید مربی؛ `auto` یعنی ارسال مستقیم به ورزشکار. (برای نسخه MVP، حالت both پیش‌فرض است.)

### مدیریت و دسترسی
- هویت حساب بر اساس Telegram ID؛ هر ورزشکار فقط داده‌های خودش را می‌بیند.
- PostgreSQL در Production وقتی `DATABASE_URL` توسط EthioDeploy تزریق شود؛ SQLite فقط برای توسعه محلی و زمانی که `DATABASE_URL` تنظیم نشده باشد.
- محدودیت اشتراک: ۳۰ روز و حداکثر ۵ برنامه در دوره، قابل تنظیم از ENV.
- پشتیبانی از خرید تکی و اشتراک در مدل داده؛ پرداخت آنلاین زرین‌پال در این نسخه به‌صورت آماده‌اتصال/غیرفعال است و تا دریافت Merchant ID و URL عمومی HTTPS فعال نمی‌شود. مدیر می‌تواند دسترسی را دستی فعال کند.
- برنامه‌های قبلی پس از انقضای اشتراک قابل مشاهده‌اند؛ ساخت برنامه جدید نیازمند دسترسی فعال است.

## فرمت پیشنهادی Excel مربی
یک فایل `.xlsx` با یک یا چند Sheet بساز. هر ردیف می‌تواند یک قانون، اصل تمرینی، نمونه برنامه یا نکته باشد.
ستون‌های پیشنهادی:
`category | title | content | tags | source`
نمونه:
`training_rule | اصل اضافه‌بار | وقتی تمام ست‌ها در بالاترین تکرار با فرم مناسب انجام شد، بار را اندکی افزایش بده. | progression | Coach notes`
اگر ستون‌ها متفاوت باشند، تمام سلول‌های غیرخالی هر ردیف به متن تبدیل و وارد دانش می‌شوند.
نکته: فایل Excel منبع دانش و روش مربی است، نه «مدل هوش مصنوعی» یا وزن‌های مدل. ربات آن را برای پاسخ‌سازی بازیابی می‌کند (روش RAG ساده).

## اجرا
1. Python 3.11 نصب کن.
2. `pip install -r requirements.txt`
3. `.env.example` را به `.env` کپی کن و `BOT_TOKEN` و `GROQ_API_KEY` را وارد کن. برای اجرای محلی بدون `DATABASE_URL`، SQLite به‌صورت خودکار استفاده می‌شود.
4. شناسه عددی تلگرام مربی را در `COACH_IDS` و مدیر را در `ADMIN_IDS` بگذار.
5. `python main.py`

## استقرار در EthioDeploy / Nixpacks
- ZIP را استخراج کن و **محتویات پوشه** را در ریشه GitHub آپلود کن، نه ZIP تنها.
- Root Directory خالی باشد اگر `main.py` و `requirements.txt` در ریشه‌اند.
- نوع سرویس: Background Worker.
- Start Command: `python main.py`
- Environment Variables: `BOT_TOKEN`, `GROQ_API_KEY`, `GROQ_MODEL`, `COACH_IDS`, `ADMIN_IDS`, `APPROVAL_MODE`. افزونه PostgreSQL در EthioDeploy متغیر `DATABASE_URL` را خودکار به برنامه تزریق می‌کند.
- وقتی `DATABASE_URL` موجود باشد، ربات از PostgreSQL 16 استفاده می‌کند و `init()` ساختار جداول را به‌صورت idempotent ایجاد می‌کند. هیچ رمز دیتابیسی را دستی در GitHub قرار نده.
- وقتی `DATABASE_URL` وجود نداشته باشد، SQLite محلی در `DATABASE_PATH` استفاده می‌شود.

## فرمان‌ها
- `/start` شروع
- `/profile` پروفایل
- `/coach` پنل مربی
- `/pending` درخواست‌های منتظر تأیید (مربی)
- `/approve ID` تأیید برنامه
- `/reject ID توضیح` رد برنامه
- `/grant TELEGRAM_ID days` فعال‌سازی دستی اشتراک
- `/stats` آمار مدیر
- `/cancel` لغو عملیات

## نکات ایمنی و حریم خصوصی
- ربات پزشک نیست و تشخیص یا درمان نمی‌دهد.
- در صورت آسیب، بیماری، دارو، درد یا علائم هشدار، تصمیم نهایی برنامه باید با متخصص واجد صلاحیت باشد.
- فایل‌های Excel ممکن است حاوی اطلاعات شخصی باشند؛ فقط داده‌های لازم را بارگذاری کنید.
- کلیدها را در GitHub قرار ندهید؛ فقط در Environment Variables هاست.
- این نسخه MVP است و قبل از فروش عمومی باید با حساب آزمایشی، آزمون فشار، پشتیبان‌گیری و بررسی امنیتی تست شود.

## FitCoach AI V3 — حالت کم‌هزینه/رایگان
- `FREE_MODE=true` به‌صورت پیش‌فرض: ساخت برنامه از نظر اشتراک قفل نیست و هزینه پرداخت درون‌برنامه‌ای وجود ندارد.
- اگر `GROQ_API_KEY` تنظیم نشود، پاسخ عمومی مبتنی بر قواعد داخلی فعال می‌شود؛ این پاسخ مدل زبانی نیست.
- اگر از API رایگان استفاده شود، سهمیه و شرایط آن تابع ارائه‌دهنده است و ممکن است تغییر کند.
- ثبت ساختاریافته تمرین، غذا، اندازه‌گیری بدن و چک‌این روزانه اضافه شده است.
- گزارش شخصی، دستور حریم خصوصی و حذف داده با تأیید دو مرحله‌ای اضافه شده‌اند.
- برای حفظ حریم خصوصی، فایل ویدئو فقط در فضای موقت پردازش می‌شود؛ برای اجرای واقعی، بررسی سیاست نگهداری فایل در هاست نیز لازم است.

### تنظیمات رایگان پیشنهادی
در Environment Variables: `FREE_MODE=true`, `APPROVAL_MODE=auto`. برای فعال‌کردن مدل زبانی در صورت داشتن سهمیه رایگان، `GROQ_API_KEY` را محرمانه وارد کن. هیچ کلید یا توکنی را داخل GitHub قرار نده.

### امکاناتی که هنوز رایگان/آماده و کامل نیستند
تحلیل تکنیک ورزشی معتبر (فراتر از نمایش نقاط بدن)، تشخیص پزشکی، اتصال ساعت هوشمند، پرداخت آنلاین، PostgreSQL مدیریت‌شده و مقیاس میلیون‌کاربره هنوز پیاده‌سازی نشده‌اند.


## PostgreSQL production backend
- EthioDeploy PostgreSQL add-on provides `DATABASE_URL`; keep external database access disabled for an app hosted on EthioDeploy.
- Install dependencies from `requirements.txt`, including `psycopg[binary]`.
- The application selects PostgreSQL automatically when `DATABASE_URL` is non-empty; otherwise it uses SQLite for local development.
- Schema initialization is additive/idempotent and does not copy or delete SQLite data. If the bot has existing SQLite data that must be retained, export/import it deliberately before switching backends.
- The current migration PR adds SQLite regression tests. A live PostgreSQL connection test still requires the hosted add-on and is not claimed as completed.

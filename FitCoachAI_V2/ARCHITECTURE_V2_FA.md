# FitCoach AI V2 — معماری و راهنمای توسعه

## تصمیم‌های محصول
- بازار: ورزشکاران (B2C)
- رابط فعلی: Telegram
- ویدئو: کلیپ کوتاه ۱ تا ۲۰ ثانیه
- خروجی فعلی ویدئو: MP4 دارای نقاط و اتصالات تخمینی بدن (pose overlay)
- مسیر آینده: گزارش تصویری و تحلیل حرکت با قواعد اختصاصی و اعتبارسنجی‌شده

## معماری مقصد
Telegram Adapter → Application Services → Domain Engines → Data Layer

### سرویس‌ها
1. Athlete Profile: مشخصات، هدف، تجهیزات، تجربه و محدودیت‌ها
2. Workout Engine: برنامه‌ریزی تمرین و ثبت جلسات
3. Nutrition Engine: محاسبه و ثبت دریافت غذایی
4. Progress Engine: اندازه‌گیری پایه، گزارش هفتگی و روز ۳۰
5. Recovery Engine: خواب، خستگی و آمادگی
6. Safety Engine: قواعد محدودیت و ارجاع به متخصص
7. Video Analysis: دریافت کلیپ، استخراج فریم، pose estimation و خروجی تصویری
8. Subscription / Notification: دسترسی و یادآوری

## خط لوله ویدئو
1. دریافت Telegram Video؛ محدودیت نسخه فعلی ۱۸ MB و ۲۰ ثانیه.
2. دانلود موقت در پوشه موقت سیستم.
3. بررسی ابعاد و مدت.
4. استخراج نقاط بدن با MediaPipe Pose.
5. ترسیم نقاط و اتصالات روی فریم‌ها با OpenCV.
6. ساخت MP4 و ارسال به کاربر.
7. حذف فایل‌های موقت پس از پایان درخواست.

### محدودیت مهم V2
این پیاده‌سازی یک **pose visualization MVP** است، نه داور تکنیک ورزشی. نقاط بدن ممکن است با پوشیدگی، زاویه نامناسب، نور کم یا حرکت سریع اشتباه شوند. خروجی نباید به‌عنوان تشخیص آسیب، اندازه‌گیری قطعی زاویه مفصل، یا تأیید ایمنی استفاده شود. ارزیابی فنی حرکت باید برای هر حرکت (اسکوات، ددلیفت، پرس سینه و...) با دوربین/زاویه مشخص، داده اعتبارسنجی‌شده و بازبینی متخصص توسعه یابد.

## نصب
نصب پایه:
```bash
pip install -r requirements.txt
```
فعال‌سازی تحلیل ویدئو:
```bash
pip install -r requirements-video.txt
```
سپس ربات را مثل قبل اجرا کن:
```bash
python main.py
```

## استقرار
- نوع سرویس: Background Worker
- Start command: `python main.py`
- سورس‌ها را از ZIP استخراج کن و محتویات را در ریشه مخزن GitHub قرار بده.
- `BOT_TOKEN`, `GROQ_API_KEY`, `COACH_IDS`, `ADMIN_IDS` را فقط در Environment Variables قرار بده.
- اگر تحلیل ویدئو لازم است، وابستگی‌های requirements-video.txt نیز باید در محیط نصب شوند. در محیط Nixpacks می‌توان دستور نصب را به Build Command افزود:
  `pip install -r requirements.txt && pip install -r requirements-video.txt`
- پردازش ویدئو CPU و RAM مصرف می‌کند؛ برای چند کاربر هم‌زمان باید صف پردازش و Worker جداگانه اضافه شود.

## وضعیت واقعی
این بسته، نسخه توسعه‌ای مبتنی بر MVP قبلی است. قابلیت pose overlay به کد اضافه شده، اما نصب وابستگی‌های ویدئو، استقرار روی هاست و آزمون end-to-end تلگرام باید در محیط مقصد انجام شود. تحلیل تکنیک ورزشی دقیق و قابلیت‌های کامل تغذیه/داشبورد ۳۰ روزه هنوز در این نسخه تکمیل نشده‌اند.


## V3 — امکانات ثبت و پایش با هزینه نرم‌افزاری صفر
- ثبت ست/تکرار/وزنه/RIR برای تمرین‌ها
- ثبت وعده و ماکروها با ورود دستی؛ محاسبه خودکار از روی عکس یا پایگاه غذایی هنوز فعال نیست
- اندازه‌گیری وزن، دور کمر، سینه، بازو و ران
- چک‌این خواب، انرژی، کوفتگی و پایبندی
- گزارش بر اساس داده‌های ثبت‌شده
- `FREE_MODE=true` برای تست رایگان بدون درگاه پرداخت
- حالت fallback بدون API: قواعد و متن‌های عمومی؛ نه LLM و نه جایگزین مربی
- حذف داده با تأیید دو مرحله‌ای

### محدودیت استقرار رایگان
تلگرام رایگان است اما ربات باید روی یک پردازشگر همیشه‌فعال اجرا شود. سرویس‌های میزبانی رایگان ممکن است خواب بروند، محدودیت CPU/RAM داشته باشند یا سیاستشان عوض شود. اجرای محلی روی کامپیوتر هزینه هاست ندارد اما با خاموش‌شدن کامپیوتر ربات قطع می‌شود. اجرای قابل اتکا و ۲۴/۷ بدون هیچ هزینه‌ای تضمین‌شدنی نیست.
